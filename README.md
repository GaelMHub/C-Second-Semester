# C-Second-Semester

> Collection of C programming exercises and projects from my second semester — covering sorting algorithms, data structures, recursion, string handling, and modular programming.

---

## Programs

| File | Description |
|---|---|
| `array_manager.c` | Interactive array manager — random init, insert, delete, search, and sort |
| `array_search.c` | Linear and/or binary search over integer arrays |
| `atm_machine.c` | Console ATM simulation — balance inquiry, deposits, and withdrawals |
| `bmi_calculator.c` | BMI calculator with sex-specific thresholds and diagnosis |
| `bubble_sort.c` | Bubble sort implementation over an integer array |
| `fibonacci.c` | Generates the Fibonacci sequence up to N terms |
| `fifo_lifo.c` | Queue (FIFO) and stack (LIFO) simulation using arrays |
| `func_calculator.c` | Function-based calculator with modular arithmetic operations |
| `function_types.c` | Demonstrates the 4 types of C functions (with/without params and return) |
| `grade_stats.c` | Grade statistics — pass/fail counts, averages, and percentages |
| `guess_game.c` | Number guessing game with random generation and attempt counter |
| `input_validator.c` | Input validation for age, grade, and name with re-prompt loop |
| `insertion_sort.c` | Insertion sort implementation over an integer array |
| `integer_average.c` | Computes the average of a set of integers entered by the user |
| `name_input.c` | Reads, stores, and displays a name using string handling |
| `number_check.c` | Checks whether a number is positive, negative, even, or odd |
| `number_compare.c` | Compares two or more numbers and identifies the largest/smallest |
| `operator_calculator.c` | Calculator using a char operator (+, -, *, /) with division-by-zero handling |
| `quick_sort.c` | Quick sort implementation using a middle-element pivot and recursion |
| `shapes_area.c` | Computes area and perimeter for multiple geometric shapes |
| `string_ops.c` | String operations — length, copy, concatenation, and comparison |
| `student_grades.c` | Student grade management — input, classification, and summary |

## Requirements

- **Compiler:** GCC (GNU Compiler Collection) or any C99-compatible compiler
- **OS:** Windows (programs use `<conio.h>` and `system("cls")`)
- **Standard:** C99

---

## How to Compile & Run

Clone the repository:

```bash
git clone https://github.com/GaelMHub/C-Second-Semester.git
cd C-Second-Semester
```

Compile any program:

```bash
gcc -Wall -std=c99 -o output_name filename.c
./output_name
```

Example:

```bash
gcc -Wall -std=c99 -o quick_sort quick_sort.c
./quick_sort
```

## Notes

- All programs were written as part of second-semester coursework.
- Code is kept simple and readable — focused on learning, not optimization.
- Each file is self-contained and can be compiled independently.
